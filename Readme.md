# Исследование данных продаж компьютерных игр в интернет-магазине «Стримчик»

## 📌 Описание проекта

Интернет-магазин **«Стримчик»** продаёт компьютерные игры по всему миру. Из открытых источников доступны исторические данные о продажах игр, оценки пользователей и экспертов, жанры и платформы (например, Xbox или PlayStation).

**Проблема:** игровая индустрия — одна из самых динамичных и конкурентных сфер развлечений. Успешность игры определяется множеством факторов: платформой, жанром, возрастным рейтингом, оценками критиков и пользователей. Чтобы правильно планировать рекламные кампании и делать ставку на потенциально популярный продукт, необходимо выявить закономерности успешности игр на основе исторических данных.

**Решение:** проведён анализ рынка продаж видеоигр за предыдущие годы, выявлены ключевые закономерности, составлен портрет пользователя по регионам и проверены статистические гипотезы.

---

## 🎯 Цель исследования

Выявить закономерности успешности игр путём анализа рынка продаж интернет-магазина «Стримчик» за предыдущие годы, на основе которого спрогнозировать продажи в последующем году (2017) и спланировать рекламные кампании.

---

## 📂 Данные

**Файл:** `games.csv`

| Признак | Описание |
|---|---|
| `Name` | название игры |
| `Platform` | платформа |
| `Year_of_Release` | год выпуска |
| `Genre` | жанр игры |
| `NA_sales` | продажи в Северной Америке (млн копий) |
| `EU_sales` | продажи в Европе (млн копий) |
| `JP_sales` | продажи в Японии (млн копий) |
| `Other_sales` | продажи в других странах (млн копий) |
| `Critic_Score` | оценка критиков (максимум 100) |
| `User_Score` | оценка пользователей (максимум 10) |
| `Rating` | рейтинг от организации ESRB (Entertainment Software Rating Board) |

> ⚠️ Данные за 2016 год могут быть неполными.

**Аббревиатура ESRB** — ассоциация, определяющая возрастной рейтинг компьютерных игр: «Для взрослых», «Для детей младшего возраста», «Для подростков» и т.д.

## 📊 Результаты

### Ключевые закономерности
1. **Жизненный цикл платформ** — около 11 лет; новые платформы вытесняют старые.
2. **Актуальные лидеры (2012–2016):** PS4, PS3, XOne.
3. **Влияние отзывов:** оценки критиков влияют на продажи сильнее, чем оценки пользователей.
4. **Прибыльные жанры:** шутеры, спортивные игры, экшен.
5. **Региональные различия:**
   - NA и EU: схожие предпочтения (Action, Shooter, Sports; PS4, XOne, X360/PS3).
   - JP: Role-Playing, Action, Misc; 3DS, PS3, PSV; рейтинг ESRB почти не влияет.

### Проверенные гипотезы
| Гипотеза | Результат |
|---|---|
| Рейтинги XOne и PC одинаковые | Не отвергаем (p ≈ 0.15) |
| Рейтинги Action и Sports разные | Отвергаем (p ≪ 0.05) |

## 💡 Выводы для бизнеса

1. **Прогноз на 2017 год:**
   - **NA:** экшен, шутеры, спорт; платформы PS4, XOne, X360; рейтинг M.
   - **EU:** экшен, шутеры, спорт; платформы PS4, PS3, XOne; рейтинг M.
   - **JP:** ролевые игры, экшен, misc; платформы 3DS, PS3, PSV; рейтинг не важен.

2. **Рекомендации:**
   - делать ставку на потенциально популярные жанры (шутеры, спортивные, экшен);
   - учитывать региональные различия при планировании рекламных кампаний;
   - ориентироваться на мнение критиков при продвижении игр — их оценки сильнее влияют на продажи;
   - учитывать возрастной рейтинг ESRB для NA и EU, но не для JP;
   - обратить внимание на новые платформы (PS4, XOne) как на перспективные.

3. **Дополнительные предложения:**
   - собрать данные о продажах за каждый год (а не по году выпуска) для более точного прогноза;
   - учитывать сезонность и маркетинговые бюджеты;
   - анализировать не только суммарные продажи, но и удержание игроков.
